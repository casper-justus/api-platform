# Changelog

All notable changes to this project will be documented in this file.
This project adheres to [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-05-01
### Added
- Production-grade TypeScript REST API with PostgreSQL, Prisma ORM, JWT authentication, and Jest tests
- User registration and login endpoints with bcrypt password hashing
- JWT access token issuance and protected route middleware
- Prisma schema and database migrations for PostgreSQL
- Jest integration test suite covering auth and core endpoints
- Environment-based configuration via `.env`
- MIT License
- CONTRIBUTING.md guide
